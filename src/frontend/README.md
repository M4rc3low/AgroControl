# AgroControl Web

Frontend planejado em **React + TypeScript**.

A implementação será iniciada depois que a primeira API de domínio estiver estável.

## Direção visual inicial

- dashboard claro e objetivo;
- navegação lateral por módulos;
- módulos ativos, bloqueados e “em breve” visualmente distintos;
- foco em desktop, com responsividade para tablet e celular;
- dashboards com indicadores agrícolas e financeiros;
- mapas apenas quando o módulo de agricultura de precisão entrar.

## Primeiras telas planejadas

1. Login;
2. Seleção de organização/propriedade;
3. Dashboard;
4. Propriedades;
5. Talhões;
6. Safras;
7. Estoque;
8. Financeiro;
9. Catálogo de módulos / upgrade.
