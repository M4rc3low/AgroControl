# ADR-003 — Python e Java apenas onde agregam valor

**Status:** Aceito

## Decisão

- Python será usado para analytics, ML, visão computacional e processamento científico.
- Java será usado para telemetria/IoT quando o módulo exigir um serviço especializado.
- CRUDs comuns não serão duplicados apenas para demonstrar várias linguagens.

## Motivo

A arquitetura deve explicar por que cada tecnologia existe. O objetivo é um sistema coerente, não uma coleção de stacks.
