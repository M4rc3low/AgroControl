# AgroControl Intelligence

Serviço futuro em **Python + FastAPI**.

Responsabilidades previstas:

- análise de produtividade;
- modelos preditivos;
- análise de séries históricas;
- detecção de anomalias;
- processamento de imagens;
- visão computacional para imagens de drone;
- indicadores agronômicos derivados.

Este serviço **não será criado como microserviço apenas por arquitetura**. Ele entra quando houver uma função que se beneficie claramente do ecossistema Python.
